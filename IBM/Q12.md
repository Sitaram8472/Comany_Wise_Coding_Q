# Q13. Find the Missing Number

## Problem Description
Given an array containing $n - 1$ integers in the range from $1$ to $n$, with exactly one number missing, find the missing number.

### Example
- **Input:** `nums = [1, 2, 4, 5]`
- **Output:** `3`

---

## Approach: Mathematical Sum Formula
1. Determine $n$ as `nums.length + 1`.
2. Compute the expected sum of all numbers from $1$ to $n$ using the arithmetic series formula:
   $$\text{Expected Sum} = \frac{n \times (n + 1)}{2}$$
3. Traverse the array to calculate the `actualSum` of the given elements.
4. The missing number is simply `expectedSum - actualSum`.

---

## Code (Java)

```java
class Solution {
    public int findMissingNumber(int[] nums) {
        int n = nums.length + 1;

        int expectedSum = n * (n + 1) / 2;
        int actualSum = 0;

        for (int num : nums) {
            actualSum += num;
        }

        return expectedSum - actualSum;
    }
}
