# Q12. Create an Immutable Class in Java

## Problem Description
Explain immutability in Java and how to create an immutable class. An **immutable class** is a class whose state/objects cannot be modified after creation.

### Example
- **Input:** Initialize `ImmutableClass` with value `100`
- **Output:** `100`

---

## Approach & Key Rules
1. Declare the class as **`final`** to prevent inheritance and method overriding.
2. Declare all instance fields as **`private`** and **`final`** so they cannot be accessed directly or reassigned after initialization.
3. Initialize all fields via a **constructor** (using deep copies for mutable objects).
4. Do **not** provide any setter methods.
5. Provide only **getter methods** (returning defensive copies if fields are mutable objects).

---

## Code (Java)

```java
final class ImmutableClass {

    private final int value;

    public ImmutableClass(int value) {
        this.value = value;
    }

    public int getValue() {
        return value;
    }
}

public class Main {
    public static void main(String[] args) {

        ImmutableClass obj = new ImmutableClass(100);

        System.out.println(obj.getValue()); // Output: 100
    }
}
