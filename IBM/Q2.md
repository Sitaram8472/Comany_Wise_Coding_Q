# Q2. Find the Largest Element in an Array

## Problem Description
Given an array of integers, find and return the largest element in the array.

### Example
- **Input:** `[10, 25, 7, 42, 18]`
- **Output:** `42`

---

## Approach
1. Assume the first element (`arr[0]`) is the largest and store it in a variable `max`.
2. Traverse through each element in the array.
3. Compare the current element with `max`.
4. If the current element is greater than `max`, update `max` with the current element.
5. Return `max` after traversing the entire array.

---

## Code (Java)

```java
class Solution {
    public int findLargest(int[] arr) {
        int max = arr[0];

        for (int num : arr) {
            if (num > max) {
                max = num;
            }
        }

        return max;
    }
}
```

---

## Complexity Analysis
- **Time Complexity:** $O(n)$ — Requires a single traversal through the array of length $n$.
- **Space Complexity:** $O(1)$ — Uses constant extra space for the `max` variable.
