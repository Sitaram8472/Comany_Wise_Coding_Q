# Q7. Remove Duplicates from a Sorted Array

## Problem Description

Given a sorted array, remove the duplicate elements in-place and return the number of unique elements.

### Example

* **Input:** `[1, 1, 2, 2, 3, 4, 4]`
* **Output:** `4` (The modified array contains `[1, 2, 3, 4]`)

---

## Approach

1. Since the array is sorted, duplicate elements are always adjacent.
2. Maintain a pointer `index` (starting at `1`) to place the next unique element.
3. Traverse the array starting from index `1`:
   * If the current element is different from the previous element (`arr[i] != arr[i - 1]`), copy `arr[i]` to `arr[index]`.
   * Increment `index`.
4. Return `index`, which represents the count of unique elements in the array.

---

## Code (Java)

```java
class Solution {
    public int removeDuplicates(int[] arr) {
        if (arr.length == 0) {
            return 0;
        }

        int index = 1;

        for (int i = 1; i < arr.length; i++) {
            if (arr[i] != arr[i - 1]) {
                arr[index++] = arr[i];
            }
        }

        return index;
    }
}
```

---

## Complexity Analysis

* **Time Complexity:** $O(n)$ — Single pass through the array.
* **Space Complexity:** $O(1)$ — Modifies the input array in-place using constant auxiliary space.
