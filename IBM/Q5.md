# Q5. Calculate the Factorial of a Number

## Problem Description

Given a non-negative integer $n$, calculate its factorial.  
The factorial of $n$ ($n!$) is the product of all positive integers from $1$ to $n$.

### Example

* **Input:** `5`
* **Output:** `120`

---

## Approach: Recursion

1. **Base Case:** If $n = 0$, return $1$ (since $0! = 1$).
2. **Recursive Step:** Otherwise, calculate `factorial(n - 1)`.
3. Multiply the result by $n$.
4. Repeat recursively until reaching the base case ($n = 0$).

---

## Code (Java)

```java
class Solution {
    public int factorial(int n) {
        if (n == 0) {
            return 1;
        }

        return n * factorial(n - 1);
    }
}
```

---

## Complexity Analysis

* **Time Complexity:** $O(n)$ — The function makes $n + 1$ recursive calls.
* **Space Complexity:** $O(n)$ — Requires space on the call stack for $n + 1$ recursive stack frames.
