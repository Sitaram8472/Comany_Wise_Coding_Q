# Q19. Implement a Queue Using Two Stacks

## Problem Description
Implement a First-In-First-Out (FIFO) queue using two stacks. The queue should support standard `enqueue` (push element to back) and `dequeue` (remove element from front) operations.

### Example
- **Actions:**
  - `enqueue(10)`
  - `enqueue(20)`
  - `enqueue(30)`
  - `dequeue()` $\rightarrow$ `10`
  - `dequeue()` $\rightarrow$ `20`
  - `dequeue()` $\rightarrow$ `30`

---

## Approach: Two-Stack Reversal
1. Use **`stack1`** exclusively for `enqueue` (push) operations.
2. Use **`stack2`** exclusively for `dequeue` (pop) operations.
3. When a `dequeue` operation is requested:
   - If `stack2` is not empty, pop and return its top element.
   - If `stack2` is empty, pop all elements from `stack1` and push them onto `stack2` until `stack1` is empty. This effectively reverses the order of elements, restoring FIFO ordering.
   - Pop and return the top element from `stack2`.

---

## Code (Java)

```java
import java.util.Stack;

class QueueUsingStacks {
    private Stack<Integer> stack1 = new Stack<>();
    private Stack<Integer> stack2 = new Stack<>();

    // Add an item to the back of the queue
    public void enqueue(int x) {
        stack1.push(x);
    }

    // Remove the item from the front of the queue
    public int dequeue() {
        if (stack2.isEmpty()) {
            while (!stack1.isEmpty()) {
                stack2.push(stack1.pop());
            }
        }

        return stack2.pop();
    }
}
