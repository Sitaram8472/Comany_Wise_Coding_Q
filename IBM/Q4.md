# Q4. Count the Number of Vowels in a String

## Problem Description
Given a string, count the number of vowels in it. The vowels are:
- `a`, `e`, `i`, `o`, `u`

Both uppercase and lowercase vowels should be counted.

### Example
- **Input:** `"Hello World"`
- **Output:** `3`

---

## Approach
1. Convert the string into a character array.
2. Traverse through each character.
3. Check whether the character is a vowel by searching within the string `"aeiouAEIOU"`.
4. If it is present in the vowel string, increment the `count`.
5. Return the final `count`.

---

## Code (Java)

```java
class Solution {
    public int countVowels(String str) {
        int count = 0;

        for (char c : str.toCharArray()) {
            if ("aeiouAEIOU".indexOf(c) != -1) {
                count++;
            }
        }

        return count;
    }
}
```

---

## Complexity Analysis
- **Time Complexity:** $O(n)$ — Traverses the string of length $n$ once.
- **Space Complexity:** $O(n)$ — Uses $O(n)$ auxiliary space to create the character array with `toCharArray()`.
