# Q14. Merge Two Sorted Arrays

## Problem Description
Given two sorted arrays, merge them into a single sorted array.

### Example
- **Input:** `arr1 = [1, 3, 5]`, `arr2 = [2, 4, 6]`
- **Output:** `[1, 2, 3, 4, 5, 6]`

---

## Approach: Two Pointers
1. Create a result array with a length equal to the combined lengths of `arr1` and `arr2`.
2. Use two pointers: `i` for `arr1` and `j` for `arr2`, along with a pointer `k` for `result`.
3. Compare the elements at `arr1[i]` and `arr2[j]`.
4. Place the smaller element into `result[k]` and increment the corresponding pointers.
5. If one array is completely traversed, copy the remaining elements of the other array into `result`.

---

## Code (Java)

```java
import java.util.Arrays;

class Solution {
    public int[] mergeSortedArrays(int[] arr1, int[] arr2) {

        int[] result = new int[arr1.length + arr2.length];

        int i = 0;
        int j = 0;
        int k = 0;

        while (i < arr1.length && j < arr2.length) {
            if (arr1[i] < arr2[j]) {
                result[k++] = arr1[i++];
            } else {
                result[k++] = arr2[j++];
            }
        }

        while (i < arr1.length) {
            result[k++] = arr1[i++];
        }

        while (j < arr2.length) {
            result[k++] = arr2[j++];
        }

        return result;
    }
}
```

---

## Dry Run
Given `arr1 = [1, 3, 5]` and `arr2 = [2, 4, 6]`:

- $1 < 2 \implies \text{add } 1$
- $3 > 2 \implies \text{add } 2$
- $3 < 4 \implies \text{add } 3$
- $5 > 4 \implies \text{add } 4$
- $5 < 6 \implies \text{add } 5$
- Remaining in `arr2` $\implies \text{add } 6$

**Result:** `[1, 2, 3, 4, 5, 6]`

---

## Complexity Analysis
- **Time Complexity:** $O(n + m)$ — Where $n$ and $m$ are the lengths of `arr1` and `arr2`. Each element is processed once.
- **Space Complexity:** $O(n + m)$ — Required space to store the merged array of size $n + m$.
