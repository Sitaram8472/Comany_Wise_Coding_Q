# Q18. Implement Singleton Design Pattern

## Problem Description
Explain the Singleton design pattern in Java and demonstrate its implementation. A **Singleton pattern** ensures that a class has only one instance throughout the application lifecycle and provides a global point of access to it.

### Example Usage
```java
Singleton obj1 = Singleton.getInstance();
Singleton obj2 = Singleton.getInstance();

System.out.println(obj1 == obj2); // Output: true
