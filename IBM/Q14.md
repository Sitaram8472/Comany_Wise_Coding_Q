# Q15. Rotate a Matrix 90 Degrees Clockwise

## Problem Description

Given an $n \times n$ matrix, rotate the matrix 90 degrees clockwise in-place.

### Example

**Input:**
```text
1 2 3
4 5 6
7 8 9
```

**Output:**
```text
7 4 1
8 5 2
9 6 3
```

---

## Approach

The matrix can be rotated 90 degrees clockwise in two steps:

1. **Transpose the matrix:** Swap `matrix[i][j]` with `matrix[j][i]`.
2. **Reverse every row:** Reverse elements in each individual row from left to right.

---

## Code (Java)

```java
class Solution {

    public void rotate(int[][] matrix) {

        int n = matrix.length;

        // Transpose the matrix
        for (int i = 0; i < n; i++) {
            for (int j = i; j < n; j++) {
                int temp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = temp;
            }
        }

        // Reverse each row
        for (int i = 0; i < n; i++) {
            int left = 0;
            int right = n - 1;

            while (left < right) {
                int temp = matrix[i][left];
                matrix[i][left] = matrix[i][right];
                matrix[i][right] = temp;

                left++;
                right--;
            }
        }
    }
}
```

```

8 5 2
9 6 3
```

---

## Complexity Analysis

- **Time Complexity:** $O(n^2)$ — Visiting each element twice (once during transposition and once during row reversal).
- **Space Complexity:** $O(1)$ — Done completely in-place without auxiliary matrix allocation.
