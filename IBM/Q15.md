# Q16. Implement an LRU Cache in Java

## Problem Description
Implement a Least Recently Used (LRU) Cache in Java. An LRU Cache evicts the least recently accessed item when its capacity limit is reached.

### Example
- **Capacity:** `3`
- **Actions:**
  - `put(1, "One")`
  - `put(2, "Two")`
  - `put(3, "Three")`
  - `get(1)` *(Marks key 1 as recently used)*
  - `put(4, "Four")` *(Evicts key 2 as it is the least recently used)*
- **Output:** `{3=Three, 1=One, 4=Four}`

---

## Approach: LinkedHashMap Extension
1. Extend Java's `LinkedHashMap<K, V>`.
2. Enable access-order tracking by passing `true` as the third parameter to `super(capacity, loadFactor, accessOrder)`.
3. Store the maximum `capacity`.
4. Override `removeEldestEntry(Map.Entry<K, V> eldest)` to return `true` when `size() > capacity`, automatically triggering removal of the least recently used element upon insertion.

---

## Code (Java)

```java
import java.util.LinkedHashMap;
import java.util.Map;

class LRUCache<K, V> extends LinkedHashMap<K, V> {

    private final int capacity;

    public LRUCache(int capacity) {
        super(capacity, 0.75f, true);
        this.capacity = capacity;
    }

    @Override
    protected boolean removeEldestEntry(Map.Entry<K, V> eldest) {
        return size() > capacity;
    }
}

public class Main {
    public static void main(String[] args) {

        LRUCache<Integer, String> cache = new LRUCache<>(3);

        cache.put(1, "One");
        cache.put(2, "Two");
        cache.put(3, "Three");

        cache.get(1); // Key 1 becomes most recently used

        cache.put(4, "Four"); // Key 2 is evicted

        System.out.println(cache); // Output: {3=Three, 1=One, 4=Four}
    }
}
