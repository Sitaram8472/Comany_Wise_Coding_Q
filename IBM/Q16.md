# Q17. Reverse a String Without Using Inbuilt Reverse Functions

## Problem Description
Write a Java program to reverse a given string without using any built-in reverse utility methods (like `StringBuilder.reverse()`).

### Example
- **Input:** `"hello"`
- **Output:** `"olleh"`

---

## Approach: Two-Pointer Swap
1. Convert the input string to a character array using `.toCharArray()`.
2. Initialize two pointers: `left` at index `0` and `right` at index `arr.length - 1`.
3. Swap the characters at `left` and `right` using a temporary variable `temp`.
4. Increment `left` and decrement `right` to move toward the center.
5. Repeat until `left >= right`, then construct and return a new string from the modified character array.

---

## Code (Java)

```java
class Solution {
    public String reverseString(String str) {
        char[] arr = str.toCharArray();

        int left = 0;
        int right = arr.length - 1;

        while (left < right) {
            char temp = arr[left];
            arr[left] = arr[right];
            arr[right] = temp;

            left++;
            right--;
        }

        return new String(arr);
    }
}
